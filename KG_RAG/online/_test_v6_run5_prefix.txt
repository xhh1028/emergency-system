## 二、处置步骤

### 阶段一 先期处置（0–3 分钟）

**步骤1**：指派员工携带防洪板、沙包在受影响出入口实施挡水，防止雨水继续倒灌
- 阶段/时限：先期处置 · 目标 3 分钟内完成
- 优先级：切断危险源
- 岗位：车站员工
- 依据：AIEP28 28C [步骤6、步骤9]
- 并行：【可并行】可与步骤2、步骤3同时进行
- 借鉴：【借鉴案例case_2】广州案例中运营方联合消防水务持续抽排水，挡水与排水同步开展
- 【备用：若出入口无排水设施】步骤：采用手提潜水泵排水

**步骤2**：对摔倒受伤老人进行施救并立即召唤救护车
- 阶段/时限：先期处置 · 目标 3 分钟内完成
- 优先级：人身安全
- 岗位：车站员工
- 依据：AIEP03 3A3；AIEP03 3A1
- 并行：【可并行】可与步骤1、步骤3同时进行
- 【备用：若救护车无法及时到达】步骤：安排员工陪同伤者由指定入口前往就医
- (次生：乘客受伤)

**步骤3**：值班站长通过车站广播系统（PA）宣布疏散车站，启用人工广播避免引起恐慌
- 阶段/时限：先期处置 · 目标 8 分钟内完成
- 优先级：人身安全

**步骤5**：安排员工对站台拥挤区域进行疏散引导，优先撤离老人、儿童、残障及受伤人员

## 三、升级预案

- **当前按**：IV级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤≥10人 → 升级为 III级（依据：7.2 较大事件）
  - 死亡≥3人 → 升级为 III级（依据：7.2 较大事件）
  - 连续中断行车≥6小时 → 升级为 III级（依据：7.2 较大事件）
  - 直接经济损失≥1000万元 → 升级为 III级（依据：7.2 较大事件）
  - 重伤≥50人或死亡≥10人 → 升级为 II级（依据：7.2 重大事件）
  - 连续中断行车≥24小时 → 升级为 II级（依据：7.2 重大事件）
- **升级后增补的步骤**：
  1. 成立事故调查小组并委任证物主任，负责现场证据处理、记录及安全保管（岗位：事故处理主任；依据：AIEP02 2C；AIEP02 2D）
  2. 向当地城市轨道交通运营主管部门和相关部门报告，必要时越级上报（岗位：运营单位负责人；依据：国家城市轨道交通运营突发事件应急预案 3.3）
  3. 启动Ⅲ级应急响应，由事发地城市人民政府负责应对（岗位：运营单位、市级人民政府；依据：国家城市轨道交通运营突发事件应急预案 4.1）
  4. 组织应急抢险队救援，做好受害人员抢救、人员撤离危险区及危险源控制（岗位：应急抢险队；依据：GB/T 38707 14.4.8）

## 四、四维覆盖

- **① 人员疏散**：疏散路径：站台乘客经站台两端楼梯向站厅非付费区疏散，再经未受积水影响的出入口撤离至地面安全区域；区间迫停列车乘客经应急疏散坡道向车站方向撤离，逆风而行；集合点：车站地面出入口外指定安全集结点（远离积水区域）；弱势群体优先：老人、儿童、残障人士及受伤人员优先撤离，安排员工专人引导（依据：AIEP12 12B3 [步骤1]；AIEP07 7D2 [步骤3、步骤4]；AIEP11 11A3）
- **② 关停决策**：关闭出入口/车站：关闭受积水倒灌影响的出入口，安装防洪板及沙包；区段或线路停运：视信号设备故障及积水情况，由行车调度员决定是否区段停运或线路停运（依据：AIEP28 28C [步骤6、步骤8]；城市轨道交通运营防汛防台风指南 4.1.2、4.1.5；GB/T 38707 14.2.11）
- **③ 信息报告**：报告对象：行车调度员、车站维护人员、故障报警中心、运营主管部门；时限：接报后立即报告，30分钟内书面续报；报告格式：事件性质、事发位置、伤亡人数、设备损坏程度、已采取措施、所需支援（依据：AIEP28 28C [步骤2]；AIEP02 2B1；国家城市轨道交通运营突发事件应急预案 3.3）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

## 五、关键注意事项

1. 禁止在未确认区间积水位和线路高程的情况下指令迫停列车退行或移动，防止将列车移至更深积水区段
2. 禁止在积水未阻断、防洪板未安装到位的情况下强行组织乘客疏散，防止疏散路径被积水淹没
3. 禁止发布可能引起公众恐慌的消息，疏散广播须使用规范用语并启用人工广播

## 三、升级预案

- **当前按**：IV级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤≥10人 → 升级为 III级（依据：7.2 较大事件）
  - 死亡≥3人 → 升级为 III级（依据：7.2 较大事件）
  - 连续中断行车≥6小时 → 升级为 III级（依据：7.2 较大事件）
  - 直接经济损失≥1000万元 → 升级为 III级（依据：7.2 较大事件）
- **升级后增补的步骤**：
  1. 成立事故调查小组并委任证物主任（岗位：事故处理主任；依据：AIEP02 2C；AIEP02 2D）
  2. 向省级人民政府报告并请求启动III级应急响应（岗位：运营单位负责人；依据：国家城市轨道交通运营突发事件应急预案 4.1）
  3. 协调公安、消防、医疗等外部救援力量到场（岗位：事故处理主任；依据：AIEP02 2B2）
  4. 安排公交接驳疏运受影响乘客（岗位：行车调度员；依据：国家城市轨道交通运营突发事件应急预案 6.5）

## 四、四维覆盖

- **① 人员疏散**：疏散路径：站台→楼梯→站厅非付费区→指定出入口→地面安全集合点；集合点：车站外指定安全集合点（由值班站长根据现场情况确定并广播通知）；弱势群体优先：老人、儿童、残障人士及受伤人员优先疏散，安排员工专人协助（依据：AIEP12 12B3 [步骤1]；AIEP07 7B [步骤4]）
- **② 关停决策**：关闭出入口/车站：关闭受影响出入口，安装防洪板及沙包；区段或线路停运：根据行车调度员研判，必要时中断该区段行车服务（依据：AIEP28 28C [步骤6、步骤8]；GB/T 38707 14.2.11；城市轨道交通运营防汛防台风指南 4.1.2）
- **③ 信息报告**：报告对象：行车调度员、车站维护人员、当地城市轨道交通运营主管部门；时限：接报后立即报告，最迟不超过30分钟；报告格式：口头报告后补书面报告，内容包括事件性质、位置、伤亡情况、设备损坏程度、已采取措施（依据：国家城市轨道交通运营突发事件应急预案 3.3；AIEP02 2B1）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

- 岗位：车站员工
- 依据：AIEP28 28C [步骤6、步骤9]
- 并行：【可并行】可与步骤2、步骤3同时进行
- 借鉴：【借鉴案例case_1】郑州暴雨案例中挡水设施失效导致涝水进入隧道，挡水必须第一时间执行

- 优先级：运营调整

- 并行：【可并行】可与步骤14同时进行
- 借鉴：【借鉴案例case_2】广州案例中积水消退后仍需评估设备后方可恢复服务
- 【备用：若多个车站关闭或线路继续运行必要性不足】步骤：由控制中心值班主任决策线路停运

**步骤11**：值班站长向行车调度员报告关闭受影响出入口及装设防洪设备的安排；通知行车调度员水淹最新情况，包括是否属于紧急疏散、疏散原因、列车继续行走是否有危险、是否需要中断行车服务、是否需要召唤紧急服务
- 阶段/时限：扩大响应 · 目标30分钟内完成
- 优先级：信息报告
- 岗位：值班站长

### 阶段四 恢复善后（1 小时后）

- 阶段/时限：恢复善后 · 目标60分钟内完成
- 优先级：恢复善后
- 岗位：信号设备维护人员、车站维护人员

- 【备用：若设备受浸严重无法短时恢复】步骤：维持区段停运并安排公交接驳

## 三、升级预案

- **当前按**：IV级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤≥10人 → 升级为 III级（依据：7.2 较大事件）
  - 死亡≥3人 → 升级为 III级（依据：7.2 较大事件）
  - 连续中断行车≥6小时 → 升级为 III级（依据：7.2 较大事件）
  - 直接经济损失≥1000万元 → 升级为 III级（依据：7.2 较大事件）
- **升级后增补的步骤**：
  1. 报告属地城市人民政府及省级城市轨道交通运营主管部门，请求启动III级应急响应（岗位：运营单位负责人；依据：国家城市轨道交通运营突发事件应急预案 4.1）
  2. 成立事故调查小组，委任证物主任负责现场证据处理、记录及安全保管（岗位：事故处理主任；依据：AIEP02 2C、2D）
  3. 联络外部应急救援力量（消防、公安、水务）到场支援排涝和人员救助（岗位：应急抢险人员；依据：城市轨道交通运营防汛防台风指南 4.4）
  4. 安排公交接驳疏运受影响乘客（岗位：行车调度员、车站员工；依据：国家城市轨道交通运营突发事件应急预案 6.5）

## 四、四维覆盖

- **① 人员疏散**：疏散路径：站台乘客经站台两端楼梯→站厅→非付费区→未受影响出入口撤离至地面安全区域；站厅乘客直接经出入口撤离；集合点：车站出入口外指定安全集合点（地势较高处，远离积水区域）；弱势群体优先：老人、儿童、残障人士及受伤人员优先疏散，安排员工专门引导和协助（依据：AIEP12 12B3 [步骤1]；国家城市轨道交通运营突发事件应急预案 4.2.2；AIEP07 7A2 [清人时间]）
- **② 关停决策**：关闭出入口/车站：关闭受影响出入口，安装防洪板及沙包；在入口醒目处放置车站关闭告示；区段或线路停运：根据积水及信号故障情况，由行车调度员与值班站长协调决定是否区段停运或线路停运；满足防汛指南4.1.5任一条件时由控制中心值班主任决策线路停运（依据：AIEP28 28C [步骤6、步骤8]；城市轨道交通运营防汛防台风指南 4.1.5；GB/T 38707 14.2.11）
- **③ 信息报告**：报告对象：行车调度员→OCC→运营单位负责人→属地城市轨道交通运营主管部门；涉及人员伤亡需通报公安、消防及急救；时限：接报后30分钟内报运营单位负责人及属地城市轨道交通运营主管部门；重大以上事件立即报告；报告格式：书面报告，内容包括：事件性质及准确位置、估计伤亡人数、设备及建筑结构损坏程度、已采取的措施、需要的支援（依据：AIEP02 2B1；国家城市轨道交通运营突发事件应急预案 3.3；城市轨道交通运营防汛防台风指南 3.6.1）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

- 并行：【可并行】可与步骤1同时进行
- 借鉴：【借鉴案例case_2】广州13号线案例中运营方联合消防、水务持续抽排水，提示排水需多力量协同
- 【备用：若排水至道床】步骤：及时开启主排水泵，时刻注意清除排水入处的杂物，保持流水畅通
- 【备用：若排水设施故障】步骤：立即通报车站维护人员抢修

### 阶段二 现场处置（3–15 分钟）

**步骤4**：指派车站员工前往站台疏散乘客，引导乘客经站台两端楼梯向安全出口撤离，优先引导老人、儿童、残障及受伤人员
- 阶段/时限：现场处置 · 目标3分钟内完成
- 优先级：人身安全
- 岗位：车站员工
- 依据：AIEP12 12B3 [步骤1]；AIEP07 7B [步骤4]；城市轨道交通运营防汛防台风指南（试行）4.2.1
- 并行：【可并行】可与步骤1、步骤2同时进行
- 借鉴：【借鉴案例case_1】郑州案例中疏散受阻导致重大伤亡，提示疏散必须与挡水排水同步启动，不能等积水加深后再疏散
- 【备用：若站台拥挤严重无法通行】步骤：启用人工广播稳定乘客情绪，分批引导疏散
- 【备用：若有乘客受伤无法自行撤离】步骤：安排员工搀扶或使用担架转移至安全区域
- (次生：大客流拥挤)

**步骤5**：行车调度员通知系统调度员隔离受影响区段牵引电流，并通知值班站长确认安全保护措施已做妥
- 阶段/时限：现场处置 · 目标5分钟内完成
- 优先级：切断危险源
- 岗位：行车调度员
- 依据：AIEP02 2B4；AIEP07 7C [步骤2]；GB/T 38707 14.2.11
- 并行：【可并行】可与步骤6、步骤8同时进行
- 【备用：若涉及接触轨设备故障】步骤：指示系统调度员隔离受影响区段牵引电流，提醒现场合资格员工执行接地及保护工作
- 【备用：若牵引电流无法隔离】步骤：禁止人员进入轨行区，等待系统调度员确认断电后再行动
- (次生：信号设备故障)

**步骤6**：值班站长安排车站维护人员检查设备房进水情况，对信号设备采取防水保护措施
- 阶段/时限：现场处置 · 目标5分钟内完成
- 优先级：关键设备
- 岗位：车站维护人员
- 依据：AIEP28 28C [步骤1]；AIEP28 28D [步骤1-2]；GB/T 38707 14.2.13
- 并行：【可并行】可与步骤7同时进行
- 借鉴：【借鉴案例case_2】广州案例中抽水完成后逐系统检查受浸设备并进行复运安全评估，提示设备房进水后须全面检查信号设备
- 【备用：若设备房进水严重】步骤：启动风道排雨泵或潜水泵向地面排水，同时堆放沙包防止水流入重要设备房
- 【备用：若信号设备已故障】步骤：立即通报行车调度员及故障报警中心，启动信号设备故障应急程序
- (次生：设备房进水)

**步骤7**：值班站长将车站自动售检票系统设定为紧急放行模式，指派员工按停扶手电梯或转用适当运行模式
- 阶段/时限：现场处置 · 目标5分钟内完成
- 优先级：运营调整
- 岗位：值班站长、车站员工
- 依据：AIEP12 12B2 [步骤7、步骤8]；GB/T 38707 14.2.15
- 并行：【可并行】可与步骤9、步骤11同时进行
- 【备用：若自动售检票系统故障】步骤：安排员工手动打开闸机门，引导乘客快速通过
- 【备用：若扶手电梯无法停止】步骤：安排员工在扶梯口值守，引导乘客改走楼梯

**步骤8**：值班站长根据综合人力后援计划向人力后援控制车站要求增援
- 阶段/时限：现场处置 · 目标15分钟内完成
- 优先级：运营调整
- 岗位：值班站长
- 依据：AIEP12 12B2 [步骤4]；AIEP18 18A；AIEP18 18B
- 并行：【可并行】可与步骤9、步骤10同时进行
- 【备用：若后援车站人力不足】步骤：直接向OCC报告请求协调其他车站或部门支援
- 【备用：若增援人员无法及时到达】步骤：优先保障疏散通道和受伤乘客救治岗位的人力
- (次生：大客流拥挤)

### 阶段三 扩大响应（15–60 分钟）

**步骤9**：行车调度员通知受影响区段各车站值班站长执行区间清人安排，确认安全保护措施已做妥、隧道灯已亮起
- 阶段/时限：扩大响应 · 目标15分钟内完成
- 优先级：运营调整
- 岗位：行车调度员
- 依据：AIEP07 7C [步骤4、步骤5]；GB/T 38707 14.2.11
- 并行：【可并行】可与步骤13同时进行
- 借鉴：【借鉴案例case_1】郑州案例中未查清险情即放行列车导致严重后果，提示区间清人前必须确认轨道安全条件
- 【备用：若区间积水持续上涨】步骤：优先安排列车救援将迫停列车拖至车站站台，避免区间疏散
- 【备用：若清人条件不具备】步骤：维持列车原地等待，持续监测积水情况，做好乘客安抚
- (次生：列车区间迫停)

**步骤10**：值班站长通过乘客信息系统（PIS）显示疏散信息及发布公交接驳路线数据，向乘客发布适当消息；通知行车调度员水淹最新情况，报告是否属于紧急疏散、列车继续行走是否有危险、是否需要召唤紧急服务
- 阶段/时限：扩大响应 · 目标15分钟内完成
- 优先级：信息报告
- 岗位：值班站长
- 依据：AIEP12 12B2 [步骤5]；AIEP02 2B6；AIEP27 27C；AIEP12 12B2 [步骤1]；AIEP28 28C [步骤2]；AIEP02 2B1
- 并行：【可并行】可与步骤1、步骤2、步骤3、步骤4、步骤12同时进行
- 借鉴：【借鉴案例case_2】广州案例中提供公交接驳与出行信息，提示信息发布须包含替代出行方案
- 【备用：若PIS故障】步骤：通过车站广播和人工引导发布信息
- 【备用：若公交接驳未就绪】步骤：先发布疏散信息，待接驳方案确定后补充发布
- 【备用：若无法与OCC联络】步骤：联络公安局公交总队；若仍无法联络，致电110召唤紧急服务
- 【备用：若通信中断】步骤：通过公务电话或无线手持台尝试联络OCC

### 阶段四 恢复善后（1 小时后）

**步骤11**：值班站长安排员工记录事件全过程信息，包括伤亡情况、设备损坏程度、救援时间节点，并保存现场证据
- 阶段/时限：恢复善后 · 目标60分钟内完成
- 优先级：恢复善后
- 岗位：值班站长、车站员工
- 依据：AIEP02 2C；AIEP02 2D；AIEP03 3A1；国家城市轨道交通运营突发事件应急预案5.2
- 【备用：若涉及多人重伤或死亡】步骤：成立事故调查小组，委任证物主任负责现场证据处理
- 【备用：若有独立目击证人】步骤：尽量取得目击证人的姓名、地址及联系电话

## 三、升级预案

- **当前按**：IV级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤≥10人 → 升级为 III级（依据：7.2 较大事件：重伤10-50人）
  - 死亡≥3人 → 升级为 III级（依据：7.2 较大事件：死亡3-10人）
  - 直接经济损失≥1000万元 → 升级为 III级（依据：7.2 较大事件：直接经济损失1000万-5000万元）
  - 连续中断行车≥6小时 → 升级为 III级（依据：7.2 较大事件：连续中断行车6-24小时）
  - 重伤≥50人或死亡≥10人 → 升级为 II级（依据：7.2 重大事件）
  - 连续中断行车≥24小时 → 升级为 II级（依据：7.2 重大事件：连续中断行车24小时以上）
- **升级后增补的步骤**：
  1. 启动III级应急响应，由事发地城市人民政府负责应对，成立现场指挥部（岗位：运营单位、市级人民政府；依据：国家城市轨道交通运营突发事件应急预案4.1）
  2. 成立事故调查小组，委任证物主任负责现场证据处理与保管（岗位：事故处理主任；依据：AIEP02 2C；AIEP02 2D）
  3. 向当地城市轨道交通运营主管部门和相关部门报告，按规定逐级上报（岗位：运营单位；依据：国家城市轨道交通运营突发事件应急预案3.3）
  4. 协调公安、消防、医疗等外部救援力量到场支援（岗位：OCC、值班站长；依据：AIEP02 2B2；国家城市轨道交通运营突发事件应急预案5.2）
  5. 组织对受浸信号设备、供电设备进行全面检查与复运安全评估（岗位：车站维护人员、设备专业人员；依据：城市轨道交通运营防汛防台风指南（试行）4.2.1；GB/T 38707 14.2.13）

## 四、四维覆盖

- **① 人员疏散**：疏散路径：站台乘客经站台两端楼梯向站厅疏散，再经未受积水影响的出入口撤离至地面安全区域；区间迫停列车乘客按AIEP07 7D2执行双端清人，经应急疏散坡道逆风撤离至就近车站；集合点：车站出入口外指定安全集合点（由值班站长根据现场地势确定，远离积水区域）；弱势群体优先：老人、儿童、残障人士及受伤人员优先疏散，安排员工专人引导搀扶；受伤老人优先安排救治并陪同至救护车到场（依据：AIEP12 12B3 [步骤1]；AIEP07 7B [步骤4]；AIEP07 7D2 [步骤3-4]；城市轨道交通运营防汛防台风指南（试行）4.2.1）
- **② 关停决策**：关闭出入口/车站：关闭受积水倒灌影响的出入口，安装防洪板及沙包；满足城市轨道交通运营防汛防台风指南4.1.2条件时由值班站长决策关闭出入口；区段或线路停运：行车调度员视情况采取区段停运或线路停运措施；满足城市轨道交通运营防汛防台风指南4.1.5条件时由控制中心值班主任决策线路停运（依据：AIEP28 28C [步骤6、步骤8]；城市轨道交通运营防汛防台风指南（试行）4.1.2、4.1.5；GB/T 38707 14.2.11）
- **③ 信息报告**：报告对象：行车调度员（OCC）、车站维护人员、值班经理、当地城市轨道交通运营主管部门；无法联络OCC时联络公安局公交总队或致电110；时限：立即报告，最迟不超过30分钟；后续每30分钟续报一次，重大变化随时报告；报告格式：事件性质及准确位置、估计伤亡人数、设备及建筑结构损坏程度、已采取的措施、需要的专业协助（依据：AIEP12 12B2 [步骤1]；AIEP02 2B1；国家城市轨道交通运营突发事件应急预案3.3；GB/T 38707 14.3.7）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15；AIEP19 19B；AIEP27 27C）

## 五、关键注意事项

1. 禁止在积水持续上涨且未确认沿途水位和线路高程的情况下盲目移动迫停列车或指令退行，防止将列车移至更深积水区段
2. 禁止在未隔离牵引电流、未确认轨道安全条件的情况下组织人员进入轨行区或区间疏散
3. 禁止发布可能引起公众恐慌的消息，疏散广播须使用人工广播稳定乘客情绪
