## 一、缺陷（真实案例测量暴露，case_065，1/10 触发）

```
[safety] 隔离牵引电流 步骤2 与 进入轨道 步骤2 顺序违规 → 已交换
```

**实情**：**同一个步骤同时命中 A 与 B** ——
- A（`牵引电流.{0,4}隔离`）命中 `牵引电流已隔离`；
- B（首句 `进入.{0,4}…区间`）命中 `进入区间`。

⇒ `a == b` ⇒ `seq[1], seq[1] = seq[1], seq[1]` —— **自交换（空操作）**，
但日志仍打"**已交换**"，把一处**本来顺序正确**的步骤误标为"违规"。

**影响**：误导性日志（声称修了一处违规，实际什么都没做）。顺序本身未受损。

## 二、改动（`plan_generator.py`，仅 `_enforce_traction_safety` 内，+13 行）

在"顺序违规→交换"之前插入 `a == b` 分支：

```python
    if a == b:
        # 同一步骤同时命中 A、B：交换即自交换（空操作），**不得报"已交换"**。
        act = _s(seq[a].get("action"))
        m_a = KW_TRACTION_ISO.search(act)
        m_b = KW_ENTER_TRACK.search(_first_sentence(act))
        if m_a and m_b and m_a.start() < m_b.start():
            log("[safety] 步骤%d 的 A(隔离牵引电流)、B(进入轨道) 同步且顺序正确 → 无需调整" % (a + 1))
        else:
            log("[safety] WARNING 步骤%d 的 action 内 A(隔离牵引电流)@%s 与 B(进入轨道)@%s 顺序存疑，"
                "请人工复核（本步同时命中两类，未做交换）"
                % (a + 1, m_a.start() if m_a else "-", m_b.start() if m_b else "-"))
        return seq
```

- `a == b` → **不交换、不打"已交换"**；
- 同一 `action` 内 **A 子串在 B 子串之前** → 记 `同步且顺序正确 → 无需调整`；
- **B 在 A 之前** → 记 **WARNING**（顺序存疑，请人工复核），仍**不交换**（同一步无法通过交换调整）。

**未触碰**：`KW_TRACTION_ISO` / `KW_ENTER_TRACK` 词表、TIER/POSITION_RULES/COUNT_RULES/`_flags`、其他任何逻辑（diff 已核对）。
