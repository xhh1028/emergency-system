## 一、事件定性

- **事故等级**：信息不足，暂按一般事件处置，持续跟踪升级
- **分级对照**：逐条对照《国家城市轨道交通运营突发事件应急预案》7.2 四档标准：
  - 特别重大：死亡≥30人 / 重伤≥100人 / 直接经济损失≥1亿元 / 中断行车≥24小时 —— 未命中（死亡0人、重伤0人、经济损失未明确、中断时长未明确）
  - 重大：死亡10-29人 / 重伤50-99人 / 直接经济损失5000万-1亿元 / 中断行车12-24小时 —— 未命中（死亡0人、重伤0人、经济损失未明确、中断时长未明确）
  - 较大：死亡3-9人 / 重伤10-49人 / 直接经济损失1000万-5000万元 / 中断行车6-12小时 —— 未命中（死亡0人、重伤0人、经济损失未明确、中断时长未明确）
  - 一般：死亡1-2人 / 重伤1-9人 / 直接经济损失100万-1000万元 / 中断行车<6小时 —— 命中重伤1-9人（2人受伤，其中1人伤势较重，未明确达到重伤标准，按人员受伤情况暂归此档）
  - **结论**：逐条对照7.2后，死亡0人、重伤人数未明确（2人受伤其中1人较重）、经济损失未明确、中断时长未明确，仅人员受伤情况可暂归一般事件档，但信息不足，暂按一般事件处置，持续跟踪升级。
- **响应级别**：IV级 ｜ **责任主体**：运营单位 ｜ **报告时限**：接报后30分钟内报运营单位应急指挥机构，1小时内报市级人民政府
- **影响范围**：某车站站厅内持刀伤人，2人受伤（1人较重），行凶者仍在站厅，引发乘客惊慌奔逃、站厅秩序混乱，可能波及行车组织。

## 二、处置步骤

### 阶段一 先期处置（0–3 分钟）

**步骤1**：拨打120急救电话并请求公安部门派员到场处置行凶者
- 阶段/时限：先期处置 · 目标 2 分钟内完成
- 优先级：人身安全
- 岗位：车站员工
- 依据：GB/T 38707 14.4.8；AIEP04 4A1 [步骤5]
- 并行：【可并行】可与步骤2、步骤3同时进行
- 借鉴：【借鉴案例case_1】合川路站案例中工作人员持防暴器械与持刀者隔离并报警
- 【备用：若行凶者逼近员工或乘客】步骤：立即撤离至安全区域后报警，不得正面冲突

**步骤2**：通过车站广播系统（PA）宣布疏散车站
- 阶段/时限：先期处置 · 目标 3 分钟内完成
- 优先级：人身安全
- 岗位：值班站长
- 依据：AIEP12 12B3 [步骤1]
- 并行：【可并行】可与步骤1同时进行
- 借鉴：【借鉴案例case_1】合川路站案例中站方打开出站闸机疏散乘客
- 【备用：若PA故障或需避免恐慌】步骤：启用人工广播，小心避免引起乘客恐慌
- (次生：乘客惊慌奔逃)

**步骤3**：对受伤乘客实施压迫止血等紧急救助
- 阶段/时限：先期处置 · 目标 3 分钟内完成
- 优先级：人身安全
- 岗位：车站员工
- 依据：GB/T 38707 14.4.8
- 并行：【可并行】可与步骤1同时进行
- 借鉴：【借鉴案例case_1】合川路站案例中工作人员为伤者按压止血
- 【备用：若伤势较重无法现场止血】步骤：保持伤者平卧，等待120到场，不得随意搬动

- 并行：【可并行】可与步骤5、步骤6同时进行
- 借鉴：【借鉴案例case_1】合川路站案例中站方打开出站闸机疏散乘客
- 【备用：若疏散路线受阻】步骤：按AIEP12 12B3疏散路线受阻程序，要求行车调度员安排空车协助疏散
- (次生：乘客惊慌奔逃)

**步骤5**：为伤残人士提供或安排协助撤离
- 阶段/时限：现场处置 · 目标 5 分钟内完成
- 优先级：人身安全
- 岗位：车站员工
- 依据：AIEP12 12B3 [步骤4]
- 并行：【可并行】可与步骤4、步骤6同时进行
- 【备用：若伤残人员无法立即撤离】步骤：通过值班站长通知紧急服务人员，安排优先救援

**步骤6**：封锁持刀伤人现场并隔离行凶者

**步骤7**：通知车站内其他人员包括所有租户、承包商、商铺等离开车站并前往集合地点报到

**步骤8**：查看是否所有乘客已撤离车站并前往集合地点报到

## 三、升级预案

- **当前按**：IV级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤≥10人 → 升级为 III级（依据：7.2 较大事件）
  - 死亡≥3人 → 升级为 III级（依据：7.2 较大事件）
  - 直接经济损失≥1000万元 → 升级为 III级（依据：7.2 较大事件）
  - 连续中断行车≥6小时 → 升级为 III级（依据：7.2 较大事件）
- **升级后增补的步骤**：
  1. 启动综合人力后援方案，从后援车站调派人员到事故车站（岗位：控制车站值班站长；依据：AIEP18 18B [步骤1.3]）
  2. 执行大客流综合管理控制方案B，选择响应车站限制乘客进入站台（岗位：值班经理；依据：AIEP19 19B [步骤1.1]）
  3. 通知市级人民政府和相关部门，请求公安、消防、医疗等外部支援（岗位：运营单位应急指挥机构；依据：GB/T 38707 14.4.8）

## 四、四维覆盖

- **① 人员疏散**：疏散路径：扇门打开的闸机通道、消防楼梯（若设有），及/或列车（根据情况而定）；集合点：车站外指定集合地点；弱势群体优先：伤残人士、老人、儿童、受伤人员优先撤离，安排车站员工或自愿协助的乘客陪同（依据：AIEP12 12B3 [步骤3-5]；AIEP07 7C [步骤5]）
- **② 关停决策**：关闭出入口/车站：根据情况关闭部分或全部出入口，设置铁马限制乘客进站；区段或线路停运：根据行车调度员安排，必要时区段或线路停运（依据：GB/T 38707 14.2.11；GB/T 38707 14.2.15 f)）
- **③ 信息报告**：报告对象：运营单位应急指挥机构、市级人民政府、公安部门、消防部门、急救中心；时限：接报后30分钟内报运营单位，1小时内报市级人民政府；报告格式：书面报告，包括事件时间、地点、伤亡情况、已采取措施、需要支援事项（依据：GB/T 38707 14.3.7；GB/T 38707 14.4.6）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

## 五、关键注意事项

1. 禁止在未确保自身安全的情况下与持刀行凶者正面冲突
2. 禁止在疏散过程中使用可能引起恐慌的措辞，应小心避免引起乘客恐慌
3. 禁止在未确认所有乘客已撤离前恢复车站正常运营

  - 特别重大：死亡≥30人 / 重伤≥100人 / 直接经济损失≥1亿元 / 连续中断行车≥24小时 —— 未命中（现场2人受伤，其中1人伤势较重，无死亡报告，无经济损失与中断时长数据）
  - 重大：死亡10-29人 / 重伤50-99人 / 直接经济损失5000万-1亿元 / 连续中断行车≥12小时 —— 未命中（伤亡人数远低于阈值，中断时长信息不足）
  - 较大：死亡3-9人 / 重伤10-49人 / 直接经济损失1000万-5000万元 / 连续中断行车≥6小时 —— 未命中（无死亡，重伤人数未达10人，中断时长信息不足）
  - 一般：死亡1-2人 / 重伤1-9人 / 直接经济损失100万-1000万元 / 连续中断行车≥2小时 —— 部分命中（2人受伤，其中1人伤势较重，但重伤认定需医疗机构出具证明；中断时长信息不足）

## 三、升级预案

- **当前按**：IV级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤人数≥10人 → 升级为 III级（依据：7.2 较大事件）
  - 死亡人数≥3人 → 升级为 III级（依据：7.2 较大事件）
  - 连续中断行车≥6小时 → 升级为 III级（依据：7.2 较大事件）
  - 事件被定性为恐怖袭击或涉及爆炸物 → 升级为 II级（依据：7.2 重大事件）
- **升级后增补的步骤**：
  1. 值班站长立即向市级人民政府和省级人民政府报告并请求启动更高级别应急响应（岗位：值班站长；依据：国家城市轨道交通运营突发事件应急预案 4.2.2）
  2. 行车调度员组织全线列车限速运行或部分区段停运（岗位：行车调度员；依据：GB/T 38707 14.2.11）
  3. 车站工作人员配合公安人员实施全站封闭和全面搜查（岗位：车站工作人员、公安人员；依据：国家城市轨道交通运营突发事件应急预案 4.2.2）

## 四、四维覆盖

- **① 人员疏散**：疏散路径：站厅乘客经出站闸机向最近出入口疏散，站台乘客经楼梯/扶梯向站厅方向撤离后出站；集合点：车站外指定安全集合点（如出入口外广场）；弱势群体优先：老人、儿童、残障人员及受伤人员优先撤离，安排专人协助（依据：国家城市轨道交通运营突发事件应急预案 4.2.2）
- **② 关停决策**：关闭出入口/车站：视公安人员要求关闭部分或全部出入口，保留至少一个出入口作为救援通道；区段或线路停运：若事件影响行车安全，行车调度员可安排列车越站或部分区段停运（依据：GB/T 38707 14.2.11；国家城市轨道交通运营突发事件应急预案 4.2.2）
- **③ 信息报告**：报告对象：行车调度员、控制车站、城市轨道交通运营主管部门、公安、急救；时限：接报后30分钟内口头报告、1小时内书面报告；报告格式：书面报告含事件时间、地点、伤亡情况、已采取措施、需支援事项（依据：GB/T 38707 14.3.7；国家城市轨道交通运营突发事件应急预案 4.2.2）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

## 五、关键注意事项

1. 禁止在未确认行凶者被控制前让乘客返回站厅
2. 禁止安保人员在没有防暴器械的情况下徒手与持刀者搏斗
3. 禁止在公安人员到场前擅自清理现场或破坏监控证据

## 一、事件定性

- **事故等级**：信息不足，暂按一般事件处置，持续跟踪升级
- **分级对照**：逐条对照《国家城市轨道交通运营突发事件应急预案》7.2 四档标准：
  - 特别重大：死亡≥30人 / 重伤≥100人 / 直接经济损失≥1亿元 / 连续中断行车≥24小时 —— 未命中（现场2人被刺伤，无死亡报告，重伤人数未明确，经济损失与中断时长信息不足）
  - 重大：死亡10-29人 / 重伤50-99人 / 直接经济损失5000万-1亿元 / 连续中断行车12-24小时 —— 未命中（无死亡报告，重伤人数未明确，经济损失与中断时长信息不足）
  - 较大：死亡3-9人 / 重伤10-49人 / 直接经济损失1000万-5000万元 / 连续中断行车6-12小时 —— 未命中（无死亡报告，重伤人数未明确，经济损失与中断时长信息不足）
  - 一般：死亡1-2人 / 重伤1-9人 / 直接经济损失100万-1000万元 / 连续中断行车1-6小时 —— 未命中（无死亡报告，重伤人数未明确，经济损失与中断时长信息不足；仅知2人被刺伤、其中1人伤势较重，无法确认重伤人数是否≥1人）
  - **结论**：逐条对照7.2后，四档标准均因关键信息缺失而无法确认命中，故定级为信息不足，暂按一般事件处置，持续跟踪升级。
- **响应级别**：IV级 ｜ **责任主体**：运营单位 ｜ **报告时限**：接报后30分钟内以电话或传真方式报告城市轨道交通运营主管部门，2小时内提交书面报告

## 二、处置步骤

### 阶段一 先期处置（0–3 分钟）

**步骤1**：立即拨打110、120报警及呼叫救护车，同时通知车站值班站长和行车调度员
- 阶段/时限：先期处置 · 目标1分钟内完成
- 优先级：人身安全
- 岗位：站厅值班站务员
- 依据：AIEP04 4A1 [步骤5]；国家城市轨道交通运营突发事件应急预案 4.2.2
- 并行：【可并行】可与步骤2、步骤3同时进行
- 借鉴：【借鉴案例case_1】合川路站案例中工作人员第一时间报警并呼叫急救，为伤者争取救治时间
- 【备用：若行凶者逼近，无法拨打电话】步骤：使用无线电手持台紧急呼叫行车调度员代报警

**步骤2**：通过车站广播系统（PA）发布疏散通知，引导站厅乘客从打开的出站闸机通道有序撤离车站
- 阶段/时限：先期处置 · 目标3分钟内完成
- 优先级：人身安全
- 岗位：值班站长
- 依据：AIEP12 12B3 [步骤1]；国家城市轨道交通运营突发事件应急预案 4.2.2
- 并行：【可并行】可与步骤5、步骤6同时进行
- 借鉴：【借鉴案例case_1】合川路站案例中站方打开出站闸机疏散乘客，避免拥挤踩踏
- 【备用：若PA广播故障】步骤：启用人工广播，使用扬声器疏散乘客
- (次生：乘客惊慌奔逃)

**步骤3**：车站员工完成疏散后查看站厅、站台、出入口是否所有乘客已撤离，并前往集合地点报到
- 阶段/时限：先期处置 · 目标10分钟内完成
- 优先级：人身安全
- 岗位：车站员工
- 依据：AIEP12 12B3 [步骤5]
- 并行：【可并行】可与步骤11同时进行
- 【备用：若发现有人未能离开现场并需救援】步骤：立即通过值班站长通知紧急服务人员

### 阶段二 现场处置（3–15 分钟）

**步骤4**：组织现场员工使用防暴器械、灭火器等与行凶者隔离，阻止其继续伤人
- 阶段/时限：现场处置 · 目标2分钟内完成
- 优先级：切断危险源
- 岗位：站厅值班站务员、车站保安
- 依据：AIEP08 8B3 [步骤7] 封锁现场；国家城市轨道交通运营突发事件应急预案 4.2.2
- 并行：【可并行】可与步骤1、步骤3同时进行
- 借鉴：【借鉴案例case_1】合川路站案例中其他人员持防暴器械与持刀者隔离，避免更多伤亡
- 【备用：若行凶者持刀冲向人群】步骤：立即引导周围乘客向远离行凶者的方向撤离，同时继续隔离

**步骤5**：对受伤乘客实施按压止血等紧急救助
- 阶段/时限：现场处置 · 目标2分钟内完成
- 优先级：人身安全
- 岗位：车站员工
- 依据：国家城市轨道交通运营突发事件应急预案 4.2.2；AIEP04 4A1 [步骤5]
- 并行：【可并行】可与步骤1、步骤2同时进行
- 借鉴：【借鉴案例case_1】合川路站案例中地铁工作人员对伤者压迫止血，为送医争取时间
- 【备用：若伤势较重无法止血】步骤：保持伤者平卧，等待120急救人员到场，不得随意搬动

**步骤6**：安排车站员工在站厅各通道使用扬声器引导乘客向最近出入口撤离，优先协助老人、儿童、残障及受伤人员
- 阶段/时限：现场处置 · 目标3分钟内完成
- 优先级：人身安全
- 岗位：车站员工
- 依据：AIEP12 12B3 [步骤4]；国家城市轨道交通运营突发事件应急预案 4.2.2
- 并行：【可并行】可与步骤4同时进行
- 借鉴：【借鉴案例case_2】黄贝岭站案例中通过广播疏导和现场引导避免恐慌扩散
- 【备用：若某通道被行凶者占据】步骤：引导乘客改走其他出入口，并通知值班站长
- (次生：乘客惊慌奔逃)

**步骤7**：封锁站厅事发现场，设置警戒线，阻止无关人员进入
- 阶段/时限：现场处置 · 目标3分钟内完成
- 优先级：切断危险源
- 岗位：站厅值班站务员、车站保安
- 依据：AIEP08 8B3 [步骤7] 封锁现场；国家城市轨道交通运营突发事件应急预案 4.2.2
- 并行：【可并行】可与步骤4、步骤5同时进行
- 借鉴：【借鉴案例case_1】合川路站案例中现场隔离与疏散同步进行，避免救援通道被占用
- 【备用：若行凶者仍在现场】步骤：在确保安全前提下维持警戒，等待公安到场

**步骤8**：值班站长通知车站内所有租户、承包商、商铺人员离开车站并前往集合地点报到
- 阶段/时限：现场处置 · 目标5分钟内完成
- 优先级：人身安全
- 岗位：值班站长
- 依据：AIEP12 12B3 [步骤2]
- 并行：【可并行】可与步骤7同时进行
- 【备用：若某商铺人员无法联系】步骤：安排员工前往该商铺确认并引导撤离

### 阶段三 扩大响应（15–60 分钟）

## 三、升级预案

- **当前按**：IV级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤人数≥10人 → 升级为 III级（依据：7.2 较大事件）
  - 死亡人数≥3人 → 升级为 III级（依据：7.2 较大事件）
  - 连续中断行车≥6小时 → 升级为 III级（依据：7.2 较大事件）
  - 直接经济损失≥1000万元 → 升级为 III级（依据：7.2 较大事件）
- **升级后增补的步骤**：
  1. 值班经理宣布进入运营紧急状态，启动专项应急预案（岗位：值班经理；依据：AIEP08 8B3 [步骤9]）
  2. 值班经理请求消防部门派人员到现场，通知政府关系部工作人员（岗位：值班经理；依据：AIEP08 8B3 [步骤9]）
  3. 值班经理与公安部门负责人、事故处理主任、运营总管保持联络，统筹疏散车站、安排列车不停站或停止服务（岗位：值班经理；依据：AIEP08 8B3 [步骤9]）
  4. 行车调度员安排一列空车协助疏散乘客（岗位：行车调度员；依据：AIEP12 12B3 疏散路线受阻 [步骤2]）

## 四、四维覆盖

- **① 人员疏散**：疏散路径：打开出站闸机通道，经消防楼梯（若设有）及/或列车撤离车站；站厅乘客从最近出入口撤离；集合点：车站集合地点（按该站车站疏散计划指定）；弱势群体优先：优先协助老人、儿童、残障人士及受伤人员撤离；轮椅使用者如非紧急应留在车厢内待列车驶至安全位置（依据：AIEP12 12B3 [步骤3-5]；AIEP07 7A1）
- **② 关停决策**：关闭出入口/车站：关闭部分进站闸机，在出入口用铁马限制乘客进站；是否完全关闭出入口由值班站长根据公安部门意见决定；区段或线路停运：通知行车调度员安排列车不停站通过或调整行车交路；是否区段或线路停运由行车调度员根据GB/T 38707 14.2.11决定（依据：GB/T 38707 14.2.11；GB/T 38707 14.2.15 d)、f)）
- **③ 信息报告**：报告对象：行车调度员、值班经理、城市轨道交通运营主管部门、公安部门、120急救；时限：接报后30分钟内以电话或传真方式报告城市轨道交通运营主管部门，2小时内提交书面报告；报告格式：书面报告应包括事件发生时间、地点、伤亡人数、行凶者状态、已采取措施、疏散进度、请求支援事项（依据：GB/T 38707 14.3.7；国家城市轨道交通运营突发事件应急预案 4.2.2）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

---

## 五、关键注意事项

1. 禁止在未确认行凶者已被控制的情况下让乘客返回站厅
2. 禁止在疏散过程中使用电梯，必须引导乘客走楼梯或自动扶梯（改变走向后）
3. 禁止在未征得公安部门同意的情况下清理现场或移动任何物品
