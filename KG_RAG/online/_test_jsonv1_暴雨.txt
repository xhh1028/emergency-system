## 一、事件定性

- **事故等级**：信息不足，暂按一般事件处置，持续跟踪升级
- **分级对照**：逐条对照《国家城市轨道交通运营突发事件应急预案》7.2 四档标准：
  - 特别重大：死亡≥30人 / 重伤≥100人 / 直接经济损失≥1亿元 / 连续中断行车≥24小时 —— 未命中（无死亡报告，重伤人数未达100人，经济损失未达1亿元，中断时长未达24小时）
  - 重大：死亡10-29人 / 重伤50-99人 / 直接经济损失5000万-1亿元 / 连续中断行车24小时以上 —— 未命中（无死亡报告，重伤人数未达50人，经济损失未达5000万元，中断时长未达24小时）
  - 较大：死亡3-9人 / 重伤10-49人 / 直接经济损失1000万-5000万元 / 连续中断行车6-24小时 —— 未命中（无死亡报告，重伤人数未达10人，经济损失未达1000万元，中断时长未达6小时）
  - 一般：死亡3人以下 / 重伤10人以下 / 直接经济损失50万-1000万元 / 连续中断行车2-6小时 —— 未命中（死亡0人符合，但重伤人数、经济损失、中断时长均未确认，无法判定命中）

## 二、处置步骤

### 阶段一 先期处置（0–3 分钟）

**步骤1**：首名抵达现场的员工搜集事件性质、准确位置、估计伤亡人数、设备损坏情况，决定所需专业协助（消防、公安、工程支持），通过对讲机或电话直接通知行车调度员，或通过值班站长转告。
- 阶段/时限：先期处置 · 目标 2 分钟内完成
- 优先级：信息报告
- 岗位：首名抵达现场的前线员工
- 依据：AIEP02 2B1 [全部]
- 并行：【可并行】可与步骤2、步骤3同时进行
- 【备用：若无法与OCC联络】步骤：联络公安局公交总队；若仍无法联络，致电110召唤紧急服务

**步骤2**：值班站长前往水淹现场视察，重点查看出入口和楼梯口积水情况，评估水淹严重程度；同时安排车站员工在出入口铺设防滑垫、粘贴提示滑倒标志，通过PIS发布天气情况及注意事项。
- 阶段/时限：先期处置 · 目标 3 分钟内完成
- 优先级：切断危险源
- 岗位：值班站长、车站员工
- 依据：AIEP28 28C [步骤1、步骤3]
- 并行：【可并行】可与步骤1、步骤3同时进行
- 借鉴：【借鉴案例case_1】郑州暴雨案例教训：进水征兆应触发停运研判，不能等列车失电后才停运
- 【备用：若出入口积水已漫过台阶】步骤：立即安排关闭受影响出入口，准备防洪板和沙包

**步骤3**：值班站长通知行车调度员及车站维护人员水淹最新情况；安排员工在出入口使用防洪板和沙包防止雨水倒灌，关闭受影响的车站入口；安排保洁人员清扫出入口、楼梯及易滑倒区域积水。
- 阶段/时限：先期处置 · 目标 5 分钟内完成
- 优先级：切断危险源
- 岗位：值班站长、车站员工、保洁人员
- 依据：AIEP28 28C [步骤2、步骤4、步骤6、步骤9]
- 并行：【可并行】可与步骤1、步骤2、步骤4同时进行
- 借鉴：【借鉴案例case_2】广州案例：抽排水和受浸设备检查修复需同步进行
- 【备用：若出入口无排水设施】步骤：采用手提潜水泵排水；若排水至道床，及时开启主排水泵并清除杂物保持流水畅通

**步骤4**：行车调度员接报后立即判明影响范围，通知列车驾驶员加强瞭望；若区间积水影响行车安全，及时采取区段停运、扣停列车等管控措施；若列车已迫停区间，尽量安排列车停于站台范围，无法自行运行至站台时安排救援或区间疏散。
- 阶段/时限：先期处置 · 目标 3 分钟内完成
- 优先级：运营调整
- 岗位：行车调度员
- 依据：GB/T 38707 14.2.11；AIEP28 28A [OCC应对要求]
- 并行：【可并行】可与步骤1、步骤2、步骤3同时进行
- 借鉴：【借鉴案例case_1】郑州案例教训：退行决策须核实沿途水位与线路高程，避免将列车移至更低积水区段
- 【备用：若列车无法自行运行至站台】步骤：安排列车救援或区间疏散，通知值班经理和公交总队
- (次生：列车区间迫停)

### 阶段二 现场处置（3–15 分钟）

**步骤5**：值班站长通过车站广播系统（PA）宣布疏散车站，小心避免引起乘客恐慌，必要时启用人工广播；指派员工按停扶手电梯或转用适当运行模式，在车站入口醒目处放置车站关闭告示。
- 阶段/时限：现场处置 · 目标 5 分钟内完成
- 优先级：人身安全
- 岗位：值班站长、车站员工

- 【备用：若站台拥挤严重无法正常疏散】步骤：启动大客流控制方案B，在站厅与站台楼梯连接处设置客流控制点，改变扶梯走向引导乘客走楼梯
- (次生：大客流拥挤)

**步骤6**：车站员工引导站台乘客向安全出口疏散，优先协助老人、儿童、残障人士及受伤人员撤离；将受伤老人搀扶至安全区域并立即召唤救护车，安排员工陪同救伤队由指定入口前往伤者位置。
- 阶段/时限：现场处置 · 目标 5 分钟内完成
- 优先级：人身安全
- 岗位：车站员工、值班站长
- 依据：AIEP03 3A3 [全部]；AIEP03 3A1 [全部]
- 并行：【可并行】可与步骤5、步骤7、步骤8同时进行
- 【备用：若伤者无法移动】步骤：就地设置保护区域，等待救护车到场，安排员工陪同
- (次生：乘客受伤)

**步骤7**：值班站长通知行车调度员是否属于紧急疏散及疏散原因、列车继续行走是否有危险、是否需要召唤紧急服务；若车站行车服务已中断，启动站台及车站综控室的紧急停车开关；将车站自动售检票系统设定为紧急放行模式。
- 阶段/时限：现场处置 · 目标 5 分钟内完成
- 优先级：运营调整
- 岗位：值班站长
- 依据：AIEP12 12B2 [步骤1、步骤6、步骤7]
- 并行：【可并行】可与步骤5、步骤6、步骤8同时进行
- 【备用：若无法与OCC联络】步骤：联络公安局公交总队；若仍无法联络，致电110

**步骤8**：车站维护人员前往设备房检查信号设备受淹情况，确认故障范围；行车调度员根据故障征状分析结果，指示系统调度员隔离受影响区段牵引电流，提醒现场合资格员工执行接地及保护工作。

- 借鉴：【借鉴案例case_2】广州案例：抽水完成后应逐系统检查受浸设备并进行复运安全评估
- 【备用：若信号设备故障无法短时恢复】步骤：行车调度员采取降级运行或区段停运措施，通知值班经理

- 并行：【可并行】可与步骤12同时进行

**步骤14**：雨停后对车站出入口、站厅、设备房、区间进行巡视检查，确认积水已排清、信号设备恢复正常、轨道无积水；对受浸设备逐系统检查并进行复运安全评估，满足安全条件后方可恢复服务。
- 阶段/时限：恢复善后 · 目标 60 分钟内完成
- 优先级：恢复善后
- 岗位：车站维护人员、值班站长
- 依据：AIEP28 28F [全部]；GB/T 38707 14.3.7 [全部]
- 并行：【可并行】可与步骤13同时进行
- 借鉴：【借鉴案例case_2】广州案例：积水消退后仍需评估供电、信号及其他受浸设备，满足安全条件后方可恢复服务
- 【备用：若设备受浸严重无法短时恢复】步骤：延长区段停运时间，组织专项抢修

**步骤15**：运营单位按规定对运营险性事件开展技术分析，吸取教训；将事件处置过程进行评估，总结经验教训，分析查找问题，提出改进措施，形成应急处置评估报告。
- 阶段/时限：恢复善后 · 目标 24 小时内完成
- 优先级：恢复善后
- 岗位：运营单位、调查小组
- 依据：GB/T 38707 14.3.7 [全部]；国家城市轨道交通运营突发事件应急预案 5.3 [处置评估]

## 三、升级预案

- **当前按**：IV级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤人数达到10人及以上 → 升级为 III级（依据：7.2 较大事件：重伤10-49人）
  - 直接经济损失达到1000万元及以上 → 升级为 III级（依据：7.2 较大事件：直接经济损失1000万-5000万元）
  - 连续中断行车达到6小时及以上 → 升级为 III级（依据：7.2 较大事件：连续中断行车6-24小时）
  - 出现死亡人员 → 升级为 III级（依据：7.2 较大事件：死亡3-9人）
  - 重伤人数达到50人及以上或死亡10人及以上 → 升级为 II级（依据：7.2 重大事件：死亡10-29人 / 重伤50-99人）
- **升级后增补的步骤**：
  1. 启动III级应急响应，由事发地城市人民政府负责应对，运营单位立即向城市轨道交通运营主管部门和相关部门报告，同时通告可能受到影响的单位和乘客。（岗位：运营单位、行车调度员；依据：国家城市轨道交通运营突发事件应急预案 4.1 [响应分级]；3.3 [信息报告]）
  2. 成立事故调查小组，委任证物主任，配合政府调查组开展事件原因、性质、人员伤亡、影响范围、经济损失调查。（岗位：事故处理主任、调查小组；依据：国家城市轨道交通运营突发事件应急预案 5.2 [事件调查]；AIEP02 2C [全部]）
  3. 若涉及多人重伤或死亡，消防、公安或其他政府部门进入现场独立调查时，事故处理主任须与政府执行人员保持紧密联系，协助安排进入事发现场，安排高级执行人员或事故调查小组成员陪行，按需要安排保护措施，调配内部资源协助调查，按要求移交证据并确保正确记录移交过程。（岗位：事故处理主任、调查小组；依据：AIEP02 2D [全部]）
  4. 若满足线路停运条件（如不相邻2个区段停运、多个车站关闭、控制中心进水严重影响行车指挥、复杂场景超出行车调度指挥应对能力等），由控制中心值班主任决策线路停运。（岗位：控制中心值班主任；依据：城市轨道交通运营防汛防台风指南（试行） 4.1.5 [全部]）

## 四、四维覆盖

- **① 人员疏散**：疏散路径：站台乘客经站台两端楼梯向站厅疏散，再经未受淹出入口撤离至地面安全区域；区间迫停列车乘客经应急疏散坡道向车站方向疏散，逆风而行以减低烟的影响（若涉及火灾）。；集合点：车站地面出入口外指定安全集合点（远离积水区域和潜在危险区域）。；弱势群体优先：老人、儿童、残障人士、受伤人员优先撤离；安排员工专门协助行动不便乘客；受伤老人由员工搀扶至安全区域并立即召唤救护车，安排员工陪同救伤队由指定入口前往伤者位置。（依据：AIEP12 12B3 [步骤1]；AIEP07 7A2 [全部]；AIEP03 3A3 [全部]；AIEP11 11A3 [全部]）
- **② 关停决策**：关闭出入口/车站：关闭受积水影响的车站出入口，安装防洪板和沙包防止雨水倒灌；在车站入口醒目处放置车站关闭告示。；区段或线路停运：若区间积水影响行车安全或信号设备故障无法短时恢复，行车调度员采取区段停运措施；若满足线路停运条件（如不相邻2个区段停运、多个车站关闭、控制中心进水严重影响行车指挥等），由控制中心值班主任决策线路停运。（依据：AIEP28 28C [步骤6、步骤8]；GB/T 38707 14.2.11；城市轨道交通运营防汛防台风指南（试行） 4.1.5 [全部]）
- **③ 信息报告**：报告对象：行车调度员、车站维护人员、值班经理、城市轨道交通运营主管部门、市级人民政府（视升级情况）；时限：接报后立即核实，30分钟内向城市轨道交通运营主管部门报告；初判为较大以上事件的，1小时内逐级上报至市级人民政府；报告格式：书面报告，包括事件发生时间、地点、性质、影响范围、人员伤亡情况、已采取措施、需要协调事项等（依据：国家城市轨道交通运营突发事件应急预案 3.3 [信息报告]；GB/T 38707 14.3.7 [全部]）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

---

## 五、关键注意事项

1. 严禁在未确认区间水位和线路高程的情况下指令列车退行，避免将列车移至更低积水区段（郑州案例教训）。
2. 严禁在信号设备故障未排除、牵引电流未隔离接地的情况下放行列车进入受影响区段。
3. 严禁在积水未排清、受浸设备未完成复运安全评估的情况下恢复运营服务。
