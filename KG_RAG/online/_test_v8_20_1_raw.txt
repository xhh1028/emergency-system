- 岗位：车站员工

- (次生：乘客受伤)

**步骤2**：召唤公安人员到场控制行凶者，并召唤救护车到场救治受伤乘客。

### 值班站长（7 步）

- **步骤2** ｜ 人身安全 · 先期处置 ｜ 召唤公安人员到场控制行凶者，并召唤救护车到场救治受伤乘客。

## 四、升级预案

- **当前按**：III级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤人数达到10~49人区间 → 升级为 III级（依据：7.2 较大事件）
  - 死亡人数达到3~9人区间 → 升级为 III级（依据：7.2 较大事件）
  - 连续中断行车达到6小时以上24小时以下 → 升级为 III级（依据：7.2 较大事件）
  - 死亡人数达到10~29人区间或重伤人数达到50~99人区间 → 升级为 II级（依据：7.2 重大事件）
- **升级后增补的步骤**：
  1. 公司总经理根据事态发展决定是否需要在总部成立危机管理委员会。（岗位：公司总经理；依据：AIEP02 2B8 [危机管理委员会]）
  2. 安全及质量经理为公司指派进入联合指挥中心的人员，并全力配合相关工作开展。（岗位：安全及质量经理；依据：AIEP02 2B9 [联合指挥中心]）
  3. 政府关系部派1名代表到事发现场，在获得授权后将事故详情和影响告知传媒代表。（岗位：政府关系部；依据：AIEP02 2B7 [政府关系部]）
  4. 成立事故调查小组，委任其中1名成员担任证物主任，负责在现场处理、记录及安全保管证据。（岗位：事故处理主任；依据：AIEP02 2C [事故调查小组]；AIEP02 2D [证据的保存]）

## 五、四维覆盖

- **① 人员疏散**：疏散路径：经扇门打开的闸机通道、消防楼梯（若设有）及/或列车（根据情况而定）撤离车站。；集合点：车站指定的集合地点。；弱势群体优先：伤残人士、行动不便人员优先安排协助撤离；受伤乘客优先安排救治和转运。（依据：AIEP12 12B3 [进行疏散车站] [步骤3-5]）
- **② 关停决策**：关闭出入口/车站：封锁事发现场，在出入口用铁马等备品限制乘客进站，关闭部分进站闸机。；区段或线路停运：根据事态发展由行车调度员决定是否停运或调整行车交路。（依据：GB/T 38707 14.2.15；AIEP02 2B4 [OCC]）
- **③ 信息报告**：报告对象：行车调度员、值班站长、事故处理主任、公交总队、事发地城市人民政府。；时限：接报后30分钟内电话报告、1小时内书面报告。；报告格式：书面报告应包括事件性质、位置、伤亡人数、已采取措施及所需支援。（依据：AIEP02 2B1 [首名抵达现场的前线员工]；AIEP03 3A1 [一般指引]）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

## 六、关键注意事项

1. 禁止在行凶者未被控制前让乘客或员工进入危险区域，避免造成新的人员伤亡。
2. 禁止发布可能引起公众恐慌的消息，疏散广播须小心避免引起乘客恐慌。
3. 禁止在未确认现场安全、未取得公安或联合指挥中心同意的情况下擅自恢复运营或放行无关人员进入现场。

## 四、升级预案

- **当前按**：III级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤人数达到10~49人 → 升级为 III级（依据：7.2 较大事故）
  - 死亡人数达到3~9人 → 升级为 III级（依据：7.2 较大事故）
  - 直接经济损失达到1000万~5000万元 → 升级为 III级（依据：7.2 较大事故）
  - 连续中断行车达到6小时以上24小时以下 → 升级为 III级（依据：7.2 较大事故）
  - 重伤人数达到50~99人或死亡人数达到10~29人或损失达到5000万~1亿元或中断达到24小时以上 → 升级为 II级（依据：7.2 重大事故）
- **升级后增补的步骤**：
  1. 通知值班经理及运营总管，启动公司危机管理委员会。（岗位：值班站长；依据：AIEP02 2B4 OCC [在危机管理委员会成立后，报告事态的进展]）
  2. 与公交总队或其他政府指定调查单位商议独立调查安排。（岗位：事故处理主任；依据：AIEP02 2C 事故调查小组 [与TCC、公交总队或其他政府指定调查单位商议有关安排]）
  3. 安排高级执行人员或事故调查小组成员陪行政府调查人员进入事发现场。（岗位：事故处理主任；依据：AIEP02 2D 证据的保存 [安排高级执行人员或事故调查小组成员陪行]）

## 五、四维覆盖

- **① 人员疏散**：疏散路径：经扇门打开的闸机通道、消防楼梯（若设有）撤离车站；若站台安全门无法自动开启，用手动方式打开站台安全门。；集合点：车站集合地点（按该站车站疏散计划指定）。；弱势群体优先：优先协助老人、儿童、残障人士及受伤人员撤离；为伤残人士提供或安排协助。（依据：AIEP12 12B3 进行疏散车站 [步骤3-5]；AIEP07 7A1 清人规则 [伤残人员如轮椅使用者应留在车厢内，待列车驶至安全位置才下车]）
- **② 关停决策**：关闭出入口/车站：关闭车站入口，在入口醒目处放置车站关闭告示；将自动售检票系统设定为紧急放行模式，打开出站闸机。；区段或线路停运：根据行车调度员指示，必要时中断行车服务；若车站行车服务已中断，启动站台及车站综控室的紧急停车开关。（依据：AIEP12 12B2 准备疏散车站 [步骤6-8]；AIEP12 12B3 进行疏散车站 [步骤1]）
- **③ 信息报告**：报告对象：行车调度员、控制车站值班站长、值班经理、事故处理主任、公交总队。；时限：接报后30分钟内电话报告、1小时内书面报告。；报告格式：报告事件性质、准确位置、估计伤亡人数、设备损坏程度、已采取的行动。（依据：AIEP02 2B1 首名抵达现场的前线员工；AIEP12 12B2 准备疏散车站 [步骤1]；AIEP03 3A1 一般指引 [必须将遇袭后已采取的行动及证人资料详情，尽快向公交总队报告]）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

## 六、关键注意事项

1. 禁止在行凶者未被控制前让乘客或员工进入危险区域，避免造成二次伤害。
2. 禁止发布可能引起公众恐慌的消息，疏散广播须小心避免引起乘客恐慌。
3. 禁止在公安部门确认现场安全前恢复车站运营或放行乘客进入。

- 依据：AIEP02 2C [事故调查小组]；AIEP02 2D [证据的保存]；AIEP02 2B2 [事故处理主任]；GB；T 38707 14.2.12 [运营期间影响正常行车的设备故障处理]
- 前置：需先完成 步骤5
- 借鉴：【借鉴案例case_1】合川路站案例中，公开通报未将案件定性为恐怖袭击，提示应保留安检与现场监控供调查，不依据现场传言直接认定安检失职。
- 【备用：若公安部门要求独立调查】步骤：与公安部门保持紧密联系，协助安排进入事发现场，移交证据并记录移交过程
- 【备用：若车站设施设备受损未修复】步骤：在确保安全的前提下采取措施先恢复有限条件行车

## 四、升级预案

- **当前按**：III级处置
- **升级触发条件**：满足以下任一条件即升级：
  - 重伤≥10人 → 升级为 III级（依据：7.2 较大事件（重伤10–49人））
  - 死亡≥3人 → 升级为 III级（依据：7.2 较大事件（死亡3–9人））
  - 直接经济损失≥1000万元 → 升级为 III级（依据：7.2 较大事件（直接经济损失1000万–5000万元））
  - 连续中断行车≥6小时 → 升级为 III级（依据：7.2 较大事件（连续中断行车6小时以上24小时以下））
- **升级后增补的步骤**：
  1. 成立事故调查小组，委任证物主任，配合政府独立调查。（岗位：事故处理主任；依据：AIEP02 2C [事故调查小组]；AIEP02 2D [证据的保存]）
  2. 向事发地省级人民政府报告，请求启动更高级别应急响应。（岗位：运营总管、值班经理；依据：国家城市轨道交通运营突发事件应急预案 4.1）
  3. 安排政府关系部代表到事发现场，向传媒发布事故详情和影响。（岗位：政府关系部；依据：AIEP02 2B7 [政府关系部]）

## 五、四维覆盖

- **① 人员疏散**：疏散路径：扇门打开的闸机通道、消防楼梯（若设有），必要时经列车疏散；集合点：车站集合地点（按该站车站疏散计划指定）；弱势群体优先：老人、儿童、残障人士、受伤人员优先疏散，安排员工或自愿协助的乘客陪同（依据：AIEP12 12B3 [进行疏散车站] [步骤3-4]；国家城市轨道交通运营突发事件应急预案 4.2.2 [现场疏散]）
- **② 关停决策**：关闭出入口/车站：关闭部分进站闸机，出入口用铁马等备品限制乘客进站；区段或线路停运：根据公安和事故处理主任指令，必要时关闭车站或部分行车线（依据：GB/T 38707 14.2.15 [大客流时车站可采取的客流管控措施]；AIEP18 18A [有关综合人力后援]）
- **③ 信息报告**：报告对象：行车调度员、值班站长、公交总队、事发地城市人民政府；时限：接报后30分钟内电话报告、1小时内书面报告；报告格式：事件性质、准确位置、估计伤亡人数、设备损坏情况、已采取的行动（依据：AIEP02 2B1 [首名抵达现场的前线员工]；AIEP03 3A1 [一般指引]；国家城市轨道交通运营突发事件应急预案 4.1）
- **④ 大客流管控**：在站厅与站台的楼梯/自动扶梯连接处设置客流控制点、改变自动扶梯走向，引导乘客走楼梯、付费区/非付费区设置回形线路、关闭部分进站闸机、进站闸机口设置铁马实现分批进闸、出入口用铁马等备品限制乘客进站、出入口外设置回形线路（依据：GB/T 38707 14.2.15）

## 六、关键注意事项

1. 禁止在未确保个人安全的情况下直接与持刀行凶者搏斗。
2. 禁止发布可能引起公众恐慌的消息。
3. 禁止在公安民警未控制行凶者前恢复车站正常运营。
